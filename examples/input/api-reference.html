Widget API Reference

The Widget API is a JSON over HTTP interface. Every endpoint requires a bearer token.

Authentication

Send the token in the Authorization header. Tokens expire after 24 hours.

curl -H "Authorization: Bearer $TOKEN" https://api.example.com/v1/widgets

Endpoints

List widgets

Returns a paginated list of widgets belonging to the authenticated account.

  • limit - page size, 1 to 100, default 20
  • cursor - opaque pagination cursor
  • status - filter by active, paused or archived

Create a widget

Creates a widget and returns it with a generated identifier.

{
  "name": "Analytics widget",
  "status": "active",
  "refresh_interval": 60
}

Status codes

CodeMeaningRetry
